## 技术与验证

`native/ui-layout/layout.cpp` 为自有 C++17 源码，编译为 `src/ui-layout.wasm` 后内嵌页面。React 管理编辑状态和界面，Canvas 2D 集中绘制，拖动按 requestAnimationFrame 合并；选择不会重新解析整份 JSON。后端只接受打开对话框登记过的文档 ID，独立调试窗口无编辑器 IPC 权限。

当前关键测试：`tests/ui-editor.test.cjs`、`tests/ui-editor-ui.cjs`（已接入 tests/ui.cjs）。UI 测试在临时目录验证原文保护、尺寸修改/撤销重做、保存、拖动、输入草稿切页、另存、5000 控件虚拟树和真实 WASM 加载。游戏不参与这些测试。

本机 5001 节点合成数据的一次测量：文档建模约 37.2 ms，100 次预热后 1000 次内核布局 P50 约 0.030 ms、P95 约 0.042 ms；WASM 5612 字节、初始线性内存 2490368 字节。这不包括画布绘制/IPC，也不是对官方编辑器的性能对比。后续需同项目测量完整点选、拖动、属性编辑和实际游戏联动。
