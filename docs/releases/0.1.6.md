# 0.1.6

## 地形与建筑导入

- Java 世界先复制到工具箱任务目录，再通过 Chunker CLI 转换为基岩来源。
- 支持选择两个角点、负坐标、来源空气处理、目标覆盖/保留策略和目标实际维度。
- 写入前保存目标完整备份，逐批读取、写入、读回核对；断线或结果不明不自动重放。
- 保存任务、预览和撤销记录，支持撤销本次批次；中断后重新打开工具箱不会丢失记录。
- 对方块状态、可读取方块实体、箱子物品和含水方块执行兼容处理，受当前网易 ModSDK 接口能力限制的部分会明确提示。

## 验证

- 服务测试：323 项回归及新增地形模型、快照、Python 运行时测试。
- Electron UI：地形导入真实 IPC、来源/目标步骤、预览确认、主题截图和撤销。
- 开发版实机：Java Anvil fixture、Chunker 1.21.0 CLI、3.10.0.436581、负坐标、目标自定义维度 3、状态方块、方块实体、覆盖/保留和撤销。

## 限制

不迁移动物、玩家、群系、世界生成规则或模组脚本。部分游戏版本无法通过 `SetLiquidBlock` 恢复含水方块时会保留方块并记录警告；实体复杂自定义字段仍需在目标存档中核对。
