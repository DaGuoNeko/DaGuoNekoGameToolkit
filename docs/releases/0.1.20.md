# 0.1.20

## 更新

- 新增模型制作工作台，支持已登记模组中的几何文件浏览与编辑，以及工具箱模型草稿。模型面板覆盖骨骼、立方体、网格、UV、贴图、四视图、定位器、显示槽位、顶点编辑、吸附、静止姿态和工程交换。
- 新增动画与动画控制器编辑：时间轴、曲线、关键帧、贝塞尔采样、粒子/声音/指令轨道、状态关系图、条件检查、断点、运行追踪、过渡曲线、完成查询和短路径混合。编辑复用 revision、备份、原子保存和未知字段保留。
- 新增 NPC 皮肤工作台，支持人型和指定模型的贴图草稿、PNG 导入/导出、像素绘制、图层、选区、蒙版、缩放/旋转、3D 默认贴图预览，以及网易 NPC 皮肤拓展包和 `.bbmodel` 交换。
- 模组内容页支持几何、动画、控制器、贴图、粒子、脚本和语言文件的列表/详情；存档模组页按完整模组同时展示行为包和资源包，并保留滚动、启用清单、UUID 和版本保护。
- 自动化接口增加内容、模型、动画、控制器、贴图和 NPC 皮肤的只读/受保护保存操作，路径必须来自列表或模型草稿，保存请求继续校验 revision、来源归属和结果大小。
- 增加 MCStudio 测试工程来源识别、网易全局配置和快捷程序管理的后续完善；进程身份读取改为独立服务，保留真实 EXE 路径与 SID 校验。
- 发布与发行验收补充模型编辑、NPC 皮肤、进程身份、内容编辑和模型控制器专项；模型制作状态、支持边界和真实游戏限制写入正式文档。

## 修复

- 修复资源内容页和存档模组页之间的来源、行为包/资源包配对和返回路径问题，避免把包目录误当成独立模组或遗漏禁用包。
- 修复模型编辑中骨骼/立方体多选、移动、复制、删除、父级变更、UV 面选择、撤销重做和外部文件冲突的原子性问题。
- 修复动画曲线、控制器状态、过渡条件和运行追踪在切换、暂停、重读、保存失败或重启后出现陈旧结果的问题。
- 修复皮肤贴图的非人型模型初始贴图、画板缩放、跨面绘制、图层/蒙版和导入导出边界，未知字段与不支持格式改为保留或明确拒绝。
- 修复 Windows 进程盘点暴露命令行参数的问题，改为只返回受保护的进程名、路径、PID 和 SID 信息。
