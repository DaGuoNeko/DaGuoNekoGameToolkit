# 0.1.19

## 更新

- 新增 MCStudio 测试工程识别：只读读取 MCStudio 工程配置、测试存档和带 `manifest.json` / `pack_manifest.json` 的模组目录，在存档库和模组库标注来源；未登记项目可以按原目录导入，世界不复制、模组文件不移动，也不修改 MCStudio 工程。
- 新增“网易全局配置”页面，浏览按用户身份保存在客户端 `storge/stream/users` 及 `users/config` 的配置文件；允许编辑已列出的普通文件，保存 JSON 前再次校验格式并创建同目录 `.bak`，保留修改时间冲突检查和路径归属保护。
- 新增“快捷程序”页面，保存最多 50 个用户选择的 `.exe`，支持名称、备注、修改和删除，并以程序目录为工作目录启动。快捷程序只保存工具箱数据，不登记存档，不移动或删除原文件。
- 运行与调试页面统一使用顶部会话上下文，性能分析、Tracy 和 UI 调试器减少重复会话选择；标题栏、工作区和窄窗口布局同步调整。
- 发布工作流加入 MCStudio/网易配置 UI 专项，确保新增入口随干净发行 EXE 验收。

## 修复

- 修复 MCStudio 工程根目录被误识别为模组的问题；只有自身或子目录存在有效包清单时才允许作为模组导入。
- 修复快捷程序路径可被符号链接、重定向路径或列表外 ID 替换的问题；保存和启动前均重新校验普通 `.exe` 文件。
- 修复网易配置保存覆盖外部修改、保存无效 JSON 或编辑未列出文件的问题；写入前保留 `.bak`，失败时保留原文件。
- 修复运行与调试页面重复显示标题、会话选择和 Tracy 控件造成的窄窗口布局拥挤。

## 验证与范围

- `npm.cmd run build` 通过；全量服务测试 470 项中 469 通过。唯一失败为本机既有 Windows WMI 进程枚举 10 秒超时，单独复测仍超时；未放宽产品超时或进程身份保护。
- MCStudio、网易配置和快捷程序服务专项 4/4 通过；MCStudio/网易配置 UI、导航 UI、Tracy UI 专项通过，覆盖真实 preload/IPC、来源标记、导入边界、JSON 冲突和普通文件路径校验。
- 本地 Windows x64 发行包已生成并核对 `release-info.json`、72 个文件的逐文件清单、ZIP 和 SHA-256；正式发布由 v0.1.19 标签工作流执行，上传 ZIP、`.sha256` 和 `latest.json`，供客户端公开更新源识别。
- MCStudio 工程、网易全局配置和快捷程序均使用本机隔离夹具；未执行真实 MCStudio 工程写入、真实游戏降级、异地联机或超大真实存档压力验证。
