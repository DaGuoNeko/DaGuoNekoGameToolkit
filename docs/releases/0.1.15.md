# 0.1.15

## 更新

- 联机房间增加本次开房的游戏版本选择，仅列出已适配自动入房的开发版并保存选择；未选择时跟随存档配置及全局默认，所选版本用于本次启动与网络规则，不改写存档配置和模组列表。
- 已运行的存档按当前游戏指纹核对所选版本，拒绝切换到不同构建；同构建的另一安装副本不改变当前运行进程及其网络规则路径。
- 补充 Java 离线存档编辑器候选工具、外部程序集成方式与许可边界文档；本版本不内置该工具，也不增加 Java 游戏运行时控制。

## 修复

- 修复固定房间复用被 Windows 保留或被其他程序占用的连接端口时出现 listen EACCES / EADDRINUSE、无法创建房间的问题；启动网络前检查原端口，仅在端口拒绝或占用时重新分配，其他错误继续明确失败。
- 端口修复保留房间身份、邀请码和凭据，原子保存新端口，并让网络白名单、房间服务与完整邀请使用同一端口；页面提示重新复制完整邀请，樱花隧道本地端口无需改变。原端口仍可用时继续复用原邀请。
- 修复显式选择开房版本仍要求已有默认游戏程序，以及复用运行中存档时网络规则可能指向另一安装副本的问题。
- 同步发行房间界面测试中的全局游戏程序提示，避免旧文案断言误报失败。
- 修复云端构建受 Electron 直接下载地址 504 影响的问题：通过 GitHub 官方资产 API 获取固定版本，按锁定依赖自带的 SHA-256 清单校验后准备运行时，并复用同一 ZIP 出包；不跳过测试或完整性检查。

## 验证与范围

- npm.cmd run build 通过；全量服务测试 428/429 通过，剩余 1 项为当前 Windows 环境中的 WMI 进程盘点 10 秒超时，该测试单独复测仍超时；未放宽产品超时或进程保护。
- 房间、固定邀请、端口和重连专项服务测试 53/53 通过，覆盖端口拒绝与占用、有限回退、持久化失败保护、邀请更新、未设置默认游戏时显式选版及运行中版本保护。
- 房间 UI、更新 UI、当前发行 EXE 的 distribution-ui.cjs 和 rooms-package-ui.cjs 验证通过；发行包包含 70 个文件并通过 ZIP 清单及 SHA-256 校验。
- 版本同步为 0.1.15，正式发布通过 v0.1.15 标签触发 GitHub Actions 构建并上传 ZIP、.sha256 和 latest.json，供客户端匿名检查更新。
- 未执行真实游戏联机、异地隧道或 Java 实例控制验证；端口变化后已发送的旧完整邀请需重新分享。
