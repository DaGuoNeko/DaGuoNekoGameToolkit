# 0.1.13

## 更新

- 项目日志覆盖所有界面 IPC 异常，以及游戏进程、原版日志、地图预览、地形导入、存档功能、调试/采样、Tracy、UI 编辑器、联机后台任务和 MCP 服务的后台错误；错误事件不触发配置刷新，避免失败循环。
- 更新检查、历史加载、下载和安装准备按实际返回状态记录错误原因；自动检查成功不追加事件，失败会保留在项目日志；启动时读取并消费上次独立更新进程写入的安装结果。
- 项目日志对短时间内相同错误折叠并显示重复次数，日志文件超过上限自动压缩；写盘失败在项目日志页显示持久化错误。
- 退出清理按步骤继续执行，关键的联机、客户端和游戏会话清理失败会阻止工具箱退出并提示重试；游戏异常退出信号也会进入项目日志。
- 网络助手 Token 改为短生命周期临时文件传递，不再放在进程命令行中；启动未建立管道时会清理临时文件。

## 修复

- 修复地图预览批次回调使用地图路径作为窗口对象的问题；窗口销毁后不再发送后台批次消息，临时目录清理失败会保留原始错误。
- 修复更新下载失败时临时包清理错误被吞掉、旧下载计划残留和安装结果无法在客户端启动后恢复的问题。
- 修复联机错误恢复后不再记录、远端脚本同步和清理失败缺少项目日志，以及 MCP 路由错误可能重复记录的问题。
