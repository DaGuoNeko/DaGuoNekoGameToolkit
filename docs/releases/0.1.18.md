# 大果喵游戏工具箱 0.1.18

## 更新

- 存档卡片统一为“打开存档控制台”入口，在工作区切换概览、地图、世界数据、模组和设置；编辑、保存或取消存档设置时保留当前控制台位置。
- 世界数据改为进入当前存档工作区后自动异步加载，外部来源选择后自动读取。提前进入数据页显示扫描进度，跨子页复用同一任务；切换来源、读取范围或退出时取消旧请求，防止旧响应覆盖当前存档。保留重新扫描，未生成的存档不发起扫描。
- 世界数据按存档启用清单、包 UUID/版本及已知脚本布局开启 NPC、任务、对话、指令库和属性分类；网易 ExtraData 按实际保存内容提供，不把遗留数据或同名文件夹当作模组已启用的证据。
- 数据页采用分类、对象列表和详情分栏，增加业务摘要、双向引用、局部关系展开、字段路径导航及分页读取。比较支持中文字段说明、物品槽位和前后值；界面适配深浅主题、窄窗口和缩放。
- 基岩/网易目录存档支持离线字段及已识别业务内容编辑，提供草稿、变更预览、备份保存、写后校验和有冲突检查的撤销。写入绑定服务端扫描证据，保留来源身份、原记录哈希、存档占用检查、主机互斥、数据库锁及原始类型；不直接修改对象身份、坐标、存储格式或未知二进制扩展。
- 增加“版本与兼容”：分别编辑存档最低兼容/最后打开版本标记，以及工具箱允许启动的最低/最高客户端构建号。启动前复核范围，设置范围后无法可靠识别的构建会被拒绝；直接使用其他启动器不受此限制。
- 返回数据页时在后台校验并复用有效快照，命中后跳过重复解码和解压；保持四份快照上限，来源变化、淘汰或写入后重新读取。隐藏子页不轮询进度，列表只生成简短摘要，选中对象后才生成详细字段；大对象编码使用一次键索引，避免反复线性查找。
- MCP 只读查询增加对象 ID、引用方向/状态和 JSON Pointer 字段分页；编辑保存仍通过界面预览确认。发布工作流增加导航、世界数据编辑及自动加载的发行验收。

## 修复

- 修复未保存的字段和版本草稿随普通浏览缓存被淘汰的问题；草稿独立保留，保存、恢复为原值或明确放弃后释放。
- 修复备份恢复因外部改动被拒绝后，错误提示被自动刷新清掉的问题。
- 修复业务投影与原始 ExtraData 共用对象 ID、不同玩家扩展数据身份混淆及业务字段类型证据遗漏的问题；Java 中同名普通 scriptData 字符串不再按网易扩展解码。
- 不同扫描范围、模组条件或不完整结果的比较只标记某侧未读到，不断言新增或删除；容器物品按可确认的槽位配对，避免数组顺序变化造成误报。
- 同步存档控制台入口相关的界面回归路径，保持设置字段、草稿保护、地图定位和返回行为。

## 验证与范围

- 构建通过；本地全量服务测试 466 项中 465 通过。唯一失败为本机既有 Windows WMI 进程枚举 10 秒超时，单独复测仍超时；未放宽产品超时或进程身份保护。
- 世界数据业务、自动加载、导航、工作区、地形导入、地图预览及本机联机选择七项 Electron 专项通过，覆盖真实 preload/IPC、缓存失效、旧响应隔离、草稿缓存压力、编辑保存、恢复冲突、版本设置、比较导出、地形写入/撤销及主题/缩放。
- 本地 Windows x64 ZIP 包含 72 个文件，清单和 SHA-256 校验通过；发行 EXE 的首次启动、空用户数据、内置 runtime、配置持久化、无外部 Node/Python PATH，以及世界数据编辑和自动加载验收通过。
- 正式发布由 v0.1.18 标签工作流在干净源码上重新构建，并执行全量服务与发行 EXE 检查，上传版本 ZIP、对应 .sha256 和 latest.json，供客户端公开更新源识别。本地构建产物不代替正式 Release。
- ZIP/MCWORLD 与 Java 来源保持只读。自动备份用于恢复本次改动记录，不代替完整世界备份；改变兼容版本标记不会转换新版区块、实体或实验性内容，也不保证旧游戏能够打开。
- 验证使用合成存档和隔离测试数据；未进行真实游戏降级、剧情执行、超大真实存档压力或异地联机验收。
