# 0.1.7

## 更新

- 新增“启动联机客户端”，可以选择要加入的主存档；存档控制台也可直接“加入此存档测试”。
- 多个主存档可以分别带客户端进行多人测试，运行日志显示入房目标和验证结果。
- 定向加入的客户端使用独立运行目录和下载缓存，支持两组同 UUID、同脚本名模组分别测试。

## 修复

- 修复后启动的主存档无法通过默认局域网广播被找到的问题。
- 修复快速测试主机没有永久启动配置时，无法自动启动联机客户端的问题。
- 阻止并发启动同名玩家；所选主机退出后不会自动加入其他存档。

## 验证与范围

已在开发版 3.10.0.436581 使用新建测试地图完成两主机、两客户端实测：分别入房、玩家名单正确、同名模组独立加载，热更新 A 组后 B 组保持不变。

完整多组隔离要求内置 MCDK 和上述已适配开发版。本机测试无需邀请码或樱花；各组若引用相同源码目录，修改仍会影响使用该源码的会话。
