# 0.1.17

## 更新

- 导航整理为存档、模组与资源、启动配置、运行与调试、远程联机、任务与记录、设置七个工作区。存档工作区整合概览、地图、世界数据、模组和设置；运行工具按会话归组，切换工具保留明确目标，外部查看不登记存档或创建配置。
- 存档可以打开绑定启动配置并返回，保留草稿与切换确认；会话可打开明确关联的存档。任务页优先显示进行中及失败/中断任务，已完成和取消历史按需展开。
- 新增只读世界数据扫描，支持已保存的基岩/Java NBT、网易 scriptData 与 MessagePack，保留长整数、类型和来源证据。提供世界/玩家、实体、命令方块、容器、NPC、任务及已识别业务对象的搜索、分页、地图定位、关系检查、双来源字段比较和 JSON/CSV/SVG 导出。
- MCP 新增 scan_world_data、read_world_data、world_data_scan_state、compare_world_data，支持扫描进度、取消、分页及已有快照比较；不启动游戏、不写来源数据库、不执行存档中的命令或脚本。
- 地形与建筑导入从地图预览进入，支持来源框选、目标落点及占地预览，先离线规划再确认保存与相关会话切换。保留来源副本、目标备份、运行时维度检查、预览确认、逐批回读和撤销冲突保护。
- 按资源事件刷新页面，分离日志内容与会话元数据订阅；地图复用有界区块索引和解压缓存，世界数据查询、比较及导出移到独立计算线程。模组解析、图片、包计数和字段展示复用计算，缓存保留来源变化校验、容量限制与取消清理。

## 修复

- 修复新导航下转场方向与侧栏顺序不一致、标题栏快捷入口被拖拽区域覆盖的问题；存档卡片采用固定操作行，退出工作区入口保持在左上方可达位置。
- 修复运行会话与调试连接 ID 不同导致目标关联不准确的问题，按 registrationId 和所属 PID 对应，不自动切换到其他会话。
- 修复模组根目录 items/ 下物品分类遗漏，避免内容索引和世界数据物品定义漏归类。
- 同步旧功能 UI 测试的导航入口，并将工作区、世界数据和资源刷新验收接入 GitHub Actions 的最终发行 EXE 检查。
- 修复云端更新启动器测试在进程退出后清理临时 EXE 时偶发 EPERM；仅对已校验的测试目录进行有限清理重试，保留进程退出断言和产品超时。
- 修复地形 UI 验收在小窗口内用窗口外坐标拖动地图的误报；框选前滚动画布到可见位置，按画布比例拖动，并覆盖 900×650 窗口。

## 验证与范围

- 构建通过；全量服务测试 447 项中 446 通过。唯一失败为本机既有 Windows WMI 进程盘点 10 秒超时，单独复测仍超时；未放宽产品超时或进程身份保护。
- 云端清理修正后，更新启动器、安装器和更新服务专项 17/17 通过；Windows 安装目录替换、备份、校验拒绝及启动器跨客户端退出断言继续有效。
- 工作区、性能、导航、地形导入、地图预览、配置/存档、日志、归档搜索和更新界面 9 项 Electron 专项及更新网络专项通过；覆盖真实 preload/IPC，使用合成来源及游戏接口模拟，工作区深浅主题与窄屏截图已检查。
- 本地 Windows x64 发行 ZIP 包含 72 个文件，清单及 SHA-256 校验通过；发行 EXE 的首次启动、工作区入口、配置持久化、无外部 Node/Python PATH、世界数据扫描/比较/导出及资源刷新验收通过，两个独立数据 worker 均已纳入分发。
- 新增数据读取只覆盖已保存的受支持记录；动态脚本、外部模组、未生成区块和未保存状态不作完整性保证，部分扫描不能作为对象不存在的证据。不提供自动修复或数据库写回。
- 本轮使用合成夹具及隔离测试数据，未进行真实游戏剧情、异地联机、新引擎兼容认证或真实 Tracy 程序验证。性能数据是合成场景结果，不代表游戏帧率提升。
- 版本统一为 0.1.17，标签 v0.1.17 由发布工作流构建并上传版本 ZIP、SHA-256 和 latest.json，客户端通过公开更新源识别。此前更新器修复继续保留；0.1.15 及更早程序仍可能需要从安装目录之外启动后才能完成首次升级。
