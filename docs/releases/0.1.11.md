# 0.1.11

## 更新

- 更新器改为匿名读取公开 GitHub Release，不再要求 GitHub 登录或授权。
- 新增公开 `latest.json` 更新清单，下载前校验固定版本地址和 ZIP SHA-256。
- 启动时和运行期间自动检查更新，发现正式版本时弹出提示；设置页支持手动检查、下载、安装和查看近期版本说明。
- 地图预览解析移入后台线程，增加进度、取消、超时、附近区域加载和图片缓存限制。
- 文件选择授权增加有效期、文件身份复核和替换检测。
- 完成工作台视觉重构，统一设置、存档、日志、调试和联机页面的层级与状态表现。
- 地图预览支持保留旧图、按当前视野附近加载、相机位置保持、取消后等待后台线程退出，以及单次任务的内存、区块和 PNG 缓存上限；主进程在加载期间仍可响应其他 IPC。
- 文件选择记录最多保留 256 条并在 30 分钟后过期；每次使用重新核对真实路径、文件类型和文件身份，图片通过已打开句柄读取，路径被替换或链接变化时拒绝继续使用。
- 测试入口统一检查 Python 3，保留系统 Python 2.7 和游戏内 Python 2.7 的边界；地图和文件选择增加后台取消、超时、替换检测和真实 IPC/UI 验收。

## 验证与范围

- Windows x64 Electron 构建通过。
- 服务测试 391/391 通过。
- 更新、地图预览、文件选择、存档、日志、设置和其他 Electron UI 专项通过。
- GitHub Actions 已完成 Windows x64 构建、服务测试、更新 UI、地图预览、文件选择和发行 EXE 验收，并发布 ZIP、SHA-256 与 `latest.json`。
