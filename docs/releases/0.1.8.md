# 0.1.8

## 更新

- 设置页和启动配置增加游戏版本用途筛选及能力矩阵，按游戏 EXE 的实际 SHA-256 显示自动入房、独立主机和独立来宾能力。
- 本机联机客户端锁定房主启动时的游戏构建；全局版本改变、游戏文件被替换或主客机构建不一致时，不会启动错误版本的来宾。
- MCP 状态和构建时网络助手名单使用同一版本登记表，版本信息会随运行会话提供给 UI 与自动化工具。

## 修复

- 停止后的失败来宾仍显示“加入失败”或“需要处理”，保留目标存档和错误详情。
- 自动入房等待所属游戏进程完成引擎初始化后再操作 OreUI，避免冷启动较慢时在菜单尚未就绪前发送按键。
- 游戏文件指纹检查覆盖缓存、启动准备和来宾创建阶段，降低版本文件被替换导致的误配风险。

## 验证与范围

- 完整服务回归 343/343；版本能力表、未验证版本筛选、来宾版本锁定和失败日志 UI 回归通过。
- 开发版 3.10.0.436581 使用新建测试存档完成本机双开：房主与来宾成功入房，房主收到来宾，两个运行目录独立，修改全局程序后仍沿用房主构建，停止来宾不影响房主。
- 3.10.0.420447 保留自动入房登记，但独立主机和独立来宾仍待该版本实机验证；本版本不将其标记为完整隔离构建。异地樱花联机不作为本次发布验收条件。
