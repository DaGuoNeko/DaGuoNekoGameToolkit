# 0.1.10

## 更新

- MCP 自动化接口从 15 个扩展为 33 个，增加客户端分层就绪观察、断言读取与定向忽略、原始窗口截图、配置/设置/游戏选项读写、存档来源检查、资源预检、导入、克隆和固定拍摄。
- 新增 Windows 窗口观察与 Graphics Capture 探针，截图保持原始物理像素并核对窗口、进程、会话代次和断言状态；不抢桌面焦点，不发送全局键鼠输入。
- 存档启动前支持 PNG、JSON/JSONC 资源预检；默认阻止静态资源问题，明确确认后才可仅记录预检结果并尝试启动。
- 自动导入配置记录所属存档、生成时名称和 revision。未编辑、未共享且未占用的自动配置会随存档回收、恢复和永久删除同步处理，手动配置与用户已编辑配置保留。

## 修复

- 修复多层引擎断言轮询重复计数和后台忽略无响应问题；每次操作只针对最新、已校验的断言，不自动批量忽略或重放未知结果。
- 修复窗口缩略图白屏、奇数尺寸像素裁剪和大型导入期间列表等待复制队列的问题。
- 配置更新增加 revision 过期检查和备份，界面收到自动化数据变化时保留未保存草稿并刷新配置列表。

## 验证与范围

- 覆盖自动化服务、Windows 断言夹具、原始截图像素裁剪、资源预检、配置生命周期、MCP/IPC/UI 互通及存档导入专项测试。
- 本地 Python 3.12 环境下相关测试通过；完整发行验收由版本标签触发的 Windows GitHub Actions 执行。真实游戏跨维度、多屏/DPI 和异地网络仍需单独验收。
