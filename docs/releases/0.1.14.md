# 0.1.14

## 更新

- 新增“模组与内容”工作区，在保留原模组目录管理的基础上扫描已登记目录或指定存档中的行为包、资源包和常见 Bedrock 内容；支持按来源、内容类型、模组包、名称、标识符和路径筛选，并在详情面板显示包 UUID、组件属性、模型结构、动画轨道、实体关联、贴图预览和文件来源。
- 内容索引识别物品、方块、实体、模型、贴图、动画、粒子、脚本、界面、语言和其他数据文件，解析常见 JSON/JSONC、`texts/*.lang`、`item_texture.json` 与 `terrain_texture.json` 关联；重复标识符、解析失败、链接目录和扫描上限以问题面板呈现。扫描只读，不修改模组文件。
- 默认游戏窗口设置增加全屏模式；启动时将全屏选项写入本次运行的 `options.txt`，独立主机和自动加入客户端沿用各自启动快照，不改写保存的启动配置或已运行游戏。
- 项目日志任务完成状态补齐可量化进度，支持按项目和级别筛选、导出 UTF-8 日志，并显示后台操作的时间、级别、来源、方法和消息。
- 更新页在工具箱重启后恢复有效的已下载更新计划，校验版本、安装路径、EXE 路径、ZIP 文件名和 SHA-256；失效计划及其无主缓存包会清理，仍有效的共享缓存保留。
- 增加 Java 游戏实例集成方向文档，明确实例、加载器、Bridge、能力授权、来源哈希、数据隔离和后续验收边界；当前版本仍不宣称已支持 Java 游戏运行控制。

## 修复

- 修复发行版更新脚本继承旧安装目录作为 Windows 当前工作目录，导致关闭客户端后替换程序目录仍可能提示目录正在使用；安装脚本现在切换到更新缓存目录，回归测试从旧发行目录启动脚本覆盖该场景。
- 修复更新计划读取时旧版本、预发布版本、错误目标路径、篡改 ZIP 和重复计划可能恢复为可安装状态的问题。
- 修复运行时全屏覆盖缺少游戏 `options.txt` 时的启动边界，并保持模板设置、未知选项、备份和并发保护。
