# 0.1.9

## 更新

- 在 0.1.8 多版本选择与能力表的基础上，支持开发版 3.10.0.448891 的多个独立主存档和定向来宾，保留 3.10.0.436581 兼容。
- 来宾继续锁定房主启动时的实际游戏构建；设置、配置、UI 与 MCP 共用已登记版本能力，游戏文件被替换时拒绝新启动。
- MCP 和兼容主机控制台提供实际隔离原因，多开失败可明确区分设置、启动器、旧式源地图、未登记构建和已有共享会话。

## 修复

- 整合所属游戏进程的初始化完成检查与 448891 冷启动最小输入等待，降低黑屏加载期间过早发送菜单输入的风险。
- 期限到达或系统调用跨过期限后，不继续发送菜单输入或加入请求；总入房期限、原生租约及不重放规则保留。
- 保留停止后的自动入房验证、失败与待处理结果，以及目标存档和错误详情。
- 修复启动摘要尾部尚未刷新到日志文件时，客户端一直等待初始化完成记录的问题；继续核对所属进程和引擎日志。

## 验证与范围

- 0.1.9 整合后已用新建地图验证 448891 两主机、两来宾、四份私有目录、同名模组分别加载，热更新和关闭 A 组不影响 B 组。
- 主机运行后切换测试实例的全局游戏选择，UI 和 MCP 来宾仍使用房主原构建；服务与 UI 回归另行记录，最终发行包由版本发布流程构建及验收。
- 本机主机选择 UI 与版本能力、未知构建过滤、手动选择及持久化检查通过。版本发现夹具只扫描新建测试目录，避免已安装游戏影响测试场景。
- 当前已有共享兼容模式的存档需保存退出后重新启动。448891 新进程有 25 秒最小冷启动输入等待，总入房期限仍约 120 秒；初始化记录及最小等待不保证菜单已可操作，高负载下仍可能超时。
- 3.10.0.420447 保留自动入房能力，完整目录隔离仍未开放；本轮不包含异地网络验收。
