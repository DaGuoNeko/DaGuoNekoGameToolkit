# 大果喵游戏工具箱 0.1.2

- 设置页提供 GitHub 历史更新说明、手动检查和更早版本分页。
- 成员首次授权后，启动时及每 6 小时自动检查正式版；发现新版弹窗提示，同次运行不重复提示相同版本。
- 支持私有仓库更新包下载和 SHA-256 校验，下载重定向不携带授权信息。
- 安装采用同盘暂存和独立旧版备份，校验包版本与目录结构后再替换；配置、模组、存档和日志保留。
- 更新应用的公开配置随源码同步，版本标签触发自动构建、测试和发布，免去反复配置临时发布凭据。
- 修正 Electron 手动重定向兼容及 Windows 构建环境的临时目录、校验工具差异。

更新面向拥有私有仓库读取权限的成员，授权会跨重启和升级复用。主动退出、授权失效或被撤销时需重新授权。
