# 0.1.12

## 更新

- 新增 `probe_dimension_runtime`：绑定玩家实体所在维度，读取实际玩家坐标、`GetChunkMinPos`、`GetChunkMaxPos` 和候选 Y 方块结果；可选跨维度探测并恢复原位置。
- 新增 `probe_build_height`：只允许 isolated 会话，写入测试方块前保存原状态，执行写入和回读后自动恢复，返回 `before/write/readback/restored`。
- 将架构导入流程暴露为 MCP：新增 `terrain_prepare`、`terrain_capture_source`、`terrain_preview`、`terrain_apply`、`terrain_rollback` 和 `terrain_status`。
- 地形导入 MCP 支持 sourceDimension、targetDimension、坐标或 offset、覆盖/保留策略、空气导入和预览身份校验，复用原有备份、写前日志、失败保留和撤销状态机。
- 新增 `externalDataRoot` 任务数据目录；来源快照、运行目录、备份和游戏日志可写入用户指定的独立目录，并拒绝工具箱数据目录、程序目录、存档目录和目录链接。
- MCP 工具文档按客户端、配置/存档、地形/维度和观察/拍摄分组；开发记录收束为版本索引，Release Notes 作为版本详细内容唯一来源。

## 验证与范围

- Windows x64 Electron 构建通过。
- 全量服务测试 393/393 通过。
- 新增运行时维度探针、isolated 高度回读、架构导入外部目录和 MCP 工具目录专项测试通过。
- 真实游戏维度切换、高度写入和完整 MCP 导入仍需在明确的 isolated 测试会话中验收；不默认操作真实存档。
