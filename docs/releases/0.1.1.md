# 大果喵游戏工具箱 0.1.1

- 设置页显示 GitHub 历史更新信息，支持手动检查和加载更早版本。
- 首次完成成员授权后，启动时和运行期间自动检查正式版本；发现新版弹窗提示，同一次运行不重复提示相同版本。
- 区分尚未发布、仓库无权访问、授权失效和网络错误；系统代理与客户端更新请求保持一致。
- 更新包经 SHA-256 校验后安装，保留旧程序备份，失败时尝试恢复；程序外的配置、存档、模组和日志不参与替换。
- 项目共享更新应用配置；版本标签触发构建、验收和发布，无需每次配置临时发布凭据。

此版本面向拥有私有仓库读取权限的成员。GitHub 授权通常只需首次完成；主动退出、授权撤销或失效时需要重新授权。
