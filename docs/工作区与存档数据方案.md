# 工作区与存档数据方案

## 目标与业务边界

业务与入口的参考依据、模块职责和用户往返路径见[前端业务与用户路径](前端业务与用户路径.md)。其目标包括操作对象、范围、结果、异常与返回定位，不以视觉统一或减少菜单数量替代可用性验收。

以存档和运行会话为两条主线，整理现有入口、布局和上下文，再增加只读世界数据浏览、业务解释、关系检查与比较。本文同时作为实施清单与验收依据。原有服务、进程保护、IPC 白名单、备份、revision 和运行快照继续生效；不引入额外的项目数据模型，不自动升版或发布。

存档是持久化世界及其自带包；外部来源是临时打开的目录或压缩包；启动配置是可复用模板；模组资源是定义和源码；会话是一次运行及其实际快照；任务是有生命周期的后台操作。这些对象不能用一个“当前项目”隐式代替。启动配置可供多个世界复用，菜单客户端和远程来宾可以没有本地存档。

## 现状与问题

- 一级导航混合资源、模板、运行工具与系统设置，现有十三个入口缺少稳定的业务归属。
- 存档首页同时承担资源管理、客户端启动、工具启动；卡片按钮过多，控制台入口随运行状态改名。
- 地图、包管理和地形导入依赖弹窗，缺少可返回、可继续的工作位置。
- 日志、调试和 Tracy 分别选择会话，跨工具目标不连续。
- 存档包的内容浏览跳入全局模组页，局部范围与返回来源不明确。
- 页面卸载使部分筛选、焦点和选区丢失；不能用最后一个运行主机推导用户正在浏览的存档。
- “项目”有时实际表示启动配置。范围名称、可见标签、无障碍名称应一致。
- 已有地图服务读取 Java Anvil 和基岩子区块，并不是通用业务数据解析器。二进制解码、业务解释和运行验证是不同层次。

## 导航与入口

一级入口按资源（存档、模组与资源、启动配置）、运行（运行与调试、远程联机）、工具箱（任务与记录、设置）组织。

| 原入口 | 目标位置 |
|---|---|
| 存档列表、回收站 | 存档库 |
| 地图预览、外部查看 | 存档工作区的地图，或打开外部存档 |
| 存档控制台 | 存档概览及会话控制台；保存的自动操作仍归存档 |
| 存档模组 | 当前存档的模组视图 |
| 模组库、内容浏览 | 模组与资源 |
| UI 编辑器 | 模组与资源的 UI 编辑器，可直接打开独立文件 |
| 启动配置 | 独立模板入口 |
| 运行日志、游戏调试、UI 调试器、Tracy | 运行与调试的二级工具 |
| 联机房间 | 远程联机 |
| 项目日志 | 任务与记录 |
| 游戏设置、关于 | 设置的分类 |

页面参数应携带实际 worldId、sessionId、来源和返回位置；兼容既有内部页面 ID，不为导航变动重命名后端协议。资源页与会话页不共享一个可被隐式替换的目标。切页保留必要草稿、筛选、选区与浏览位置；有写入请求时仍遵守现有切换保护。

## 存档工作区

列表主要承担查找与选择，提供新建、导入、打开外部存档、回收站。卡片名称打开工作区；启动、打开、快速测试使用固定主操作行，模组、地图、目录、设置和删除使用固定工具行，不展开“更多操作”改变卡片高度。工作区左上方置顶退出入口，退出浏览不等于停止游戏。

工作区固定显示存档名称、原目录/独立副本/外部查看、状态及主要动作；提供概览、地图、世界数据、模组和设置。概览连接相关会话与任务。地图提供维度、坐标、选区、对象定位。存档设置保留世界选项、模板绑定和启动自动操作。

外部查看共用只读页面，不自动登记存档、创建配置或启动游戏。文件选择授权、真实路径校验、压缩包安全解压与生命周期保持有效。当前存档选择使用明确世界范围，不隐式按所选启动配置过滤。

地形与建筑导入有独立任务页面，既能从存档工具进入，也能接收地图选区；保存提醒、停止目标范围、来源副本、目标备份、预览、写入确认和撤销冲突检查全部保留。短编辑与确认继续使用弹窗。

## 运行与调试

会话列表区分主机、本机来宾、菜单客户端、远程来宾及已结束记录。当前目标显示世界、玩家、角色、版本和连接状态；二级工具为控制台、日志、代码与函数、UI 调试、性能（Python、内存、Native、Tracy）。

从世界打开工具时携带目标会话；工具间切换保持同一目标。目标退出、断线或代次变化不能静默改为其他会话。UI 调试器与 Tracy 独立窗口保留原生命周期与目标归属。日志的历史记录选择不改变正在运行的操作目标。后端仍校验 sessionId、generation、进程身份。

即时命令、物品与群系操作属于当前会话。保存的自定义功能和启动自动操作属于世界，界面区分立即执行与下次生效。本机多人测试使用当前主机添加客户端；远程分享单独进入远程联机。

## 配置和布局

区分工具箱设置、全局游戏启动设置、启动配置、存档设置和本次运行快照。显示继承来源和生效时机，不用统一优先级覆盖各字段不同的既有规则。UI 编辑器修改资源文件，UI 调试器修改运行时控件，两者保持独立。

顶栏显示面包屑和当前对象，提供运行会话、任务记录快捷入口。资源页使用列表/卡片；数据使用分类、结果、详情；地图和编辑器保留大画布；日志保持剩余空间填满；复杂导入使用步骤页；设置使用分类索引。窄窗口可折叠详情与次要操作，不隐藏目标、状态、未保存提示或写入范围。检查 900×650、默认窗口、缩放、深浅主题、键盘与长名称。

## 世界数据

### 读取与来源

读取已保存记录，提供命令方块、容器、实体、世界/玩家数据、原始字段和证据。保留数值类型及大整数精度，限制长度、深度、记录数、时间和内存。未知格式显示未支持，损坏记录单独报告，扫描中断或截断不能显示完整成功。源文件前后身份检查，运行中变化时拒绝将结果标为稳定快照。离线读取不执行存档里的命令或脚本，不写数据库。

使用后台工作线程，有真实进度、取消与失败状态；比较两份来源可以顺序扫描，不伪称并行。数据结果显示来源、读取时间、扫描覆盖、跳过与截断信息；长列表分页。地图、搜索结果和详情可以按坐标联动。

### 业务解释

NBT 读取之后，按有证据的格式处理网易扩展字符串和 MessagePack；支持的任务、NPC、对话、指令库等规则显式命名并限定范围。没有规则的结构仍可查看，不猜测字段含义。物品定义与箱内物品、NPC 模板与实体、任务定义与玩家进度分开标注。

业务数据默认展示名称、坐标、绑定和摘要，原始数据库键、偏移、NBT 类型与字段路径作为可展开证据。不得将临时样本名称、私人存档内容或机器路径写进正式文档与测试夹具。

### 关系、导出与比较

支持搜索、坐标表、任务/物品等对象清单导出，关系列表与关系图；明确字段引用和无法判断的动态引用分开。结果至少区分已找到、当前范围未找到、无法静态判断、读取失败。静态字符串匹配不能冒充真实调用关系，扫描未覆盖的目标不能判断为确定缺失。

比较两个目录或压缩包的同类对象，显示新增、删除、字段变化及双方来源；优先使用稳定身份（维度与位置、持久化实体标识、业务键），不以数组顺序当实体身份。不提供自动写回或修复。JSON 导出保留证据，CSV 适合表格阅读，导出前选择保存位置。

## 验收

1. 外部查看前后存档库与配置库没有新增记录，源数据不变。
2. 从存档进入包内容再返回，保持来源、筛选和目标。
3. 两个主机存在时，工具切换不混用会话；退出或代次变化明确失效。
4. 配置、UI 文档、调试属性草稿保留，副作用边界继续确认。
5. 地形任务入口变化不放宽任何已有保护。
6. 使用合成夹具验证连续 NBT、长整数、扩展长度、MessagePack、损坏输入、实体身份、关系证据、比较与导出。
7. 通过真实 preload/IPC 验证导航、外部读取、数据视图、比较、窄屏与任务状态，保留截图。
8. 构建、必要服务/UI 测试与当前版本 package 成功；区分模拟 UI、发行包和真实游戏验证，未实测项不得宣称通过。

## 实施状态

导航体验修正：转场次序直接由可见工作区及其子页面生成，避免旧页面序号与新侧栏顺序冲突。标题栏快捷键显式设为 no-drag，状态与图标入口分开；原生鼠标输入、顺序/逆序导航、记住子页后的跨组导航、固定卡片高度和置顶退出均纳入专项测试。参考取舍见 [UI 视觉重构](UI视觉重构.md#工作区交互修正)。

功能已按清单接入。主要入口为七个一级工作区，存档下有地图、世界数据、包内容和地形任务；会话下有控制台、日志、代码/函数、UI 调试和性能分析。设置与 UI 编辑器归入对应工作区，使用文档和 MCP 目录同步更新。运行会话与调试连接按登记 ID 和进程身份对应，不假设两个 ID 相同。

数据扫描具有明确范围、取消、错误、截断和有限快照缓存；网易二进制字符串按严格 UTF-8 解读且保留类型。业务规则具体支持 Custom NPC V3、旧式二元对话引用、Quest Engine 任务/目标、Miao 指令库 V2、明确命令回调与存档内物品定义。外部资源、动态脚本、其他模组版本、未生成区块及未保存状态不作完整性承诺。关系与比较保持只读，不提供自动修复。

功能实施阶段验证：构建通过；服务测试 439 项中 438 通过，Windows 进程枚举测试在此设备达到既有 10 秒超时，单独复测同样失败，未修改该测试对应的产品逻辑或超时。新增解码、关系、比较、会话映射与 MCP 相关复测通过。因此不能把全套服务测试表述为全绿。合并后 0.1.17 的验证以[发布说明](releases/0.1.17.md)为准。

相关 Electron 专项分别通过：配置/存档生命周期、日志及整份归档搜索、导入、包健康检查与 UUID 编辑、模组移除、游戏启动设置、UI 编辑器草稿与保存、代码/UI 调试及独立窗口、MCP 双客户端路由、单机入房、多主机隔离与定向停止、联机房间、更新、文件选择保护、地图像素/选区/维度和地形导入预览/写入/撤销。测试入口已按新导航更新，保留原功能与保护断言；这不等同于真实 Minecraft 游戏验收。

当前版本本地 package 已生成，ZIP 清单校验包含 71 个文件，包括独立世界数据 worker；发行 EXE 的首次启动、全部工作区入口、配置持久化和无 Node/Python PATH 验收通过。发行 EXE 内通过真实 preload/IPC 验证了外部来源授权、世界数据扫描、地图定位、双来源比较、JSON/CSV/SVG 及差异导出、任务记录、存档/配置无新增登记、切页返回、深浅主题、900×650 与 125% 缩放。隐藏窗口截图已逐张检查。

实施完成。服务测试的已知设备超时保留为明确验证限制；没有通过调整产品保护或测试超时把它改成通过。当前版本号、Git 提交和发布状态均保持原有边界，本地包需单独启动，正在运行的旧实例不会自动替换。

本轮没有真实游戏剧情验收、异地联机验收或新引擎兼容认证。UI 原生窗口专项中没有配置真实 Tracy 程序的分支不算实测。这些功能统一纳入 0.1.17；正式发布由版本标签工作流完成，本地包不等于 GitHub Release。
