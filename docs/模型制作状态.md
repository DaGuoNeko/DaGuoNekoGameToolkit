# 模型制作状态

[返回项目首页](../README.md) · [使用指南](使用指南.md) · [开发指南](开发指南.md) · [架构说明](架构说明.md)

本文是模型制作、动画预览、贴图编辑和 Blockbench 工程交换的当前状态入口。它描述工作区源码的实际能力和限制；用户操作看《使用指南》，测试命令看《开发指南》，版本变更看 `docs/releases/`。

## 目标

模型制作工作区按 Blockbench 的工作方式组织：左侧大纲和资源，中央模型/贴图/动画预览，右侧属性，底部时间轴；视觉样式、颜色、按钮、分隔条和反馈复用工具箱现有组件。目标是覆盖本项目需要的 Blockbench 相关模型制作能力，不把界面相似误称为官方完整兼容。

## 已接入的本地能力

- 模型库可以独立列出、搜索、新建、打开、删除几何文件；从模组内容进入时保留行为包和资源包上下文。
- 大纲支持骨骼、立方体、定位器和网格；可编辑父级、轴心、旋转、起点、尺寸、膨胀、镜像、盒子 UV 及按面 UV。父级循环、重复名称、过期选择和超限输入会拒绝。
- 预览支持单视图/四视图、透视与正交视角、聚焦、重置视角、滚轮缩放、平移、框选、多选、移动/旋转/缩放、整数吸附、顶点吸附和顶点对齐。视角和布局属于工具箱设置或当前会话，不写模型工程。
- UV 面板支持盒子 UV、按面 UV、旋转/缩放、基于剩余矩形区域的确定性自动排列和按面贴图分配；自动排列不旋转或缩放 UV 岛。贴图面板支持受保护的来源读取、尺寸校验、图层、蒙版、混合、选区和二维/三维绘制。
- 网格支持从立方体转换、新建顶点、建三角/四边面、删除面/顶点和有限细分；网格数据通过工具箱扩展字段保存并参与受限 `.bbmodel` 往返。
- 动画支持动画列表、循环/一次/停帧、骨骼轨道、曲线视图、关键帧插入/移动/复制/粘贴/删除、多轨选择、预览播放和撤销。贝塞尔、原生控制柄、声音、粒子、指令及动画控制器已经有对应的本地数据和预览路径。
- 控制器支持状态、动画引用、转移条件、权重、过渡、断点、模拟查询、运行记录、关系图搜索、缩放、平移、换位、拖线和撤销历史。
- 显示槽位支持 Blockbench 常用槽位的参考姿势、旋转/位移/缩放和 `dgn_display` 保存；`.bbmodel` 的 display 字段可往返。
- `.bbmodel` 支持范围受限的实体/方块立方体工程交换，保留受支持的骨骼、立方体、UV、单图或多图贴图、定位器、显示槽位和基本动画。
- NPC 皮肤工作台支持新建、导入、旧版 64×32 转 64×64、分区绘制、撤销、缩放、人物/自定义模型预览和拓展包导出。非人模型的 3D 预览优先使用对应 NPC 默认贴图，绘制画布保持当前皮肤。

## 仍然受限的范围

- 这不是官方 Blockbench 的全部功能复制。边/面拓扑编辑、完整材质系统、命名材质、插件生态和所有工程字段仍不在兼容承诺内。
- 网格、复杂 UV、图层/蒙版、效果轨道、Molang 上下文和控制器语义只覆盖当前工具箱明确支持的子集；不支持的数据会拒绝转换或保留为只读。
- `.bbmodel` 往返保持语义和受支持字段，不保证 JSON 字节、插件字段、编辑器布局或所有 Blockbench 版本完全一致。
- 本地 Three.js/Canvas 预览和离线控制器预览不能证明真实游戏加载、材质渲染、动画事件、资源包优先级或模组脚本行为正确。
- NPC 默认贴图和模型几何来自当前收录资源；缺失默认贴图会回退当前皮肤，真实资源包和游戏内朝向需要单独验收。

## 后续收口顺序

1. 以真实 Blockbench 工程样本补齐导入/导出差异，逐项记录拒绝条件和保留字段。
2. 继续补齐模型拓扑、材质、UV、动画效果轨道和控制器语义的明确子集，并为每项添加逻辑与 UI 验收。
3. 用隔离的真实游戏资源包验证模型朝向、默认贴图、动画和工程导出结果；失败时保持当前工程和草稿不变。
4. 只有上述范围稳定后，才整理版本说明、升版、提交、打标签或正式发布。
