## 2026-10-31 0.1.10 AI 自动化与存档配置生命周期

- MCP 从 15 个扩展为 33 个：增加分层就绪观察、断言读取/定向忽略、原始客户区截图、配置读写、新建配置、设置与游戏选项、存档来源检查/资源预检/导入/克隆和结构化固定拍摄。保留原工具及动态 MCDK 路由。
- Windows 探针在独立进程中核对游戏身份和断言控件，不抢焦点、不发送全局键鼠；截图保持物理像素，未验证的帧新鲜度和遮挡明确为 unknown，空白帧与尺寸/身份变化拒绝。
- 拍摄先检查 API，设置位置、维度、相机、FOV、视角、时间和天气，等待区块及参数回读并在截图后复核。HUD 尚无可靠回读，含 hudHidden 的请求在任何修改前拒绝。时间/天气会停止对应循环，失败可能部分生效，不自动重放或回滚。
- 配置修改保留 revision、JSONC 与未知字段；公开读取不回传 raw 或未知配置字段。新增 MCP 设置更新的过期检查及备份；界面刷新列表、保留未保存草稿。CLI JSONL 与 AI 共用 MCP 连接和业务校验。
- 资源预检在启动前验证 PNG 结构、JSON/JSONC 空资源路径和引用目标；默认阻止预检问题，明确确认后可仅记录并尝试启动。同类警告重复次数只提示需要处理，外部明确授权后仍可逐次忽略，固定拍摄在安全就绪前拒绝。
- 修复多层断言反复轮询的重复计数与后台按钮无响应：只向已校验的目标弹窗发送“忽略”按钮命令，支持中英文助记键标签，保留代次、身份及一次性操作防重放；不向桌面发送按键，不自动批量忽略。
- 审计及实机修正：视频流会舍弃奇数行，窗口缩略图可能只有白屏；改用 Windows Graphics Capture 原始像素及客户区裁剪，支持后台遮挡窗口，保持尺寸及进程身份校验。最小化窗口不标记为可安全拍摄；固定拍摄前后同时核对实际 UI 和玩家身份。设置白名单递归过滤未知字段。资源预检拒绝缺少图像数据的 PNG 和链接目录，汇总警告并用集合查找引用目标。
- 验证覆盖服务回归、Windows 断言、奇数尺寸像素裁剪、MCP/IPC/UI 互通、存档导入与双主机隔离；其他引擎构建、跨维度和多屏/DPI 环境须单独验收。
- 大型导入时只读列表不再等待复制队列，可读取已持久化的 copying 状态；结果不明时仍需复用原 requestId。更新器测试清理改用已有有界重试，导入 UI 等待实际 IPC 完成；外部游戏运行时可使用现有进程枚举夹具，不改变产品保护。

- 自动导入现在记录生成配置的存档 ID、原始配置 revision 和名称。未经修改、未被其他存档共享且没有运行占用的自动配置会随存档进入回收登记，恢复存档时恢复，永久删除或解除最后引用时移除。
- 手动配置、用户重命名/保存过的自动配置、共享配置、运行中配置和无法核验来源的旧配置均保留。应用启动和后续存档操作会修复中断后的孤立登记；配置索引失败时保留可重试状态。
- 覆盖了导入末尾写入失败、删除/恢复/永久删除中断、共享配置、绑定切换、重启恢复和原目录存档不删除源文件的专项测试。
- 正常配置和已经归档的配置不重复触发系统进程枚举，启动时只执行一次生命周期核对；实际回收前继续保留占用检查。
