## 当前版本

性能优化：按资源事件刷新，隔离日志与会话元数据更新；复用地图索引和解压结果，并保留来源变化与取消保护；世界数据比较/查询/导出移至专用线程；模组解析、包计数、字段详情和日志行复用计算，图片缓存设限。行为等价性与合成性能对照见[性能优化](性能优化.md)。

工作区交互修正：一级导航转场顺序与侧栏一致；标题栏会话/任务快捷键退出窗口拖拽区，采用简洁图标；存档卡片改用固定操作区，退出工作区入口置于左上方并保持可见。

业务路径补齐：存档可直达绑定配置并返回，保持草稿与切换确认；会话可按明确 worldId 打开关联存档；任务先展示进行中与失败/中断，完成历史按需展开。参考项目的模块职责、操作范围与入口关系整理在[前端业务与用户路径](前端业务与用户路径.md)。

0.1.17 汇总七个业务工作区、存档与会话上下文、外部只读查看、世界数据解码/关系/比较/导出、地图规划导入及性能优化。新增 MCP 扫描及分页查询接口，保留原存档写入与进程保护。实施边界见[工作区与存档数据方案](工作区与存档数据方案.md)，本次收口验证见 [0.1.17 发布说明](releases/0.1.17.md)。

此前 0.1.16 的更新安装修复继续保留：更新启动器不再占用安装目录，重启后的安装会等待当前进程退出。

存档页已增加内置模组浏览器：静态健康检查、清单与 manifest 对照、依赖诊断、单包编辑、版本同步和确认后的 UUID 重绑；写操作保留独立恢复备份并受存档占用与文件 revision 保护。

## 长期架构节点

- 地形导入从存档地图预览进入，来源框选与目标落点共用离线地图；先规划，再确认保存与会话切换，最后运行时预览并确认写入。备份、回读和撤销保护沿用原链路，详见使用指南。

- 业务域整理：renderer、shared、Electron domains、native、scripts 和 tests 已按职责分层；详见[架构说明](架构说明.md)。
- 存档生命周期：快速测试、来源快照、配置 revision、存档回收恢复和按最新配置重启由同一套服务状态机管理。
- 多客户端边界：主机、来宾、sessionId、generation、引擎指纹、源码来源和独立数据目录必须分别核对；本机多人默认使用存档房主加定向来宾。
- AI 自动化：MCP 通过 stdio/本机鉴权接口进入现有服务，工具按客户端、配置/存档、地形/维度和观察/拍摄分组；详细 schema 见 [AI 自动化接口](AI自动化.md)。
- UI 文档：通用界面规则见 [UI 视觉重构](UI视觉重构.md)，UI 编辑器和官方引擎限制分别见 [UI_EDITOR_STATUS](UI_EDITOR_STATUS.md) 与 [EDITOR_ENGINE](EDITOR_ENGINE.md)。

提交历史中的 `release: 0.1.x` 提交正文与对应 Release Notes 保持同源，便于从 Git、GitHub Release 和软件更新页查看同一版本信息。
