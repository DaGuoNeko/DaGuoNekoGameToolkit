## 2026-10-24 授权成员版本更新

- 设置页增加私有 GitHub Release 更新面板：成员通过 GitHub 授权后检查版本、查看 Release 说明、下载 ZIP 并校验 SHA-256。
- 下载完成后由独立更新脚本在旧程序退出后替换程序目录并重启；用户数据、存档、日志和模组目录不参与替换。
- 设置页提供分页历史、手动检查和启动/运行期间的自动提示；区分没有正式发布、仓库无权访问、授权失效和网络错误。
- 公开 OAuth App Client ID 随源码同步，构建不依赖本机遗留配置。版本标签触发 Actions 构建、测试和草稿资产上传，完整资产就绪后再正式发布；客户端不包含维护者凭据。
- 更新脚本重新校验 ZIP、版本和路径，同盘暂存并保留唯一旧版备份；下载重定向不转发授权头，后台检查不打断下载和安装计划。
- 新增服务、Windows 安装和真实 IPC/UI 的专项测试；网络夹具验收与真实 GitHub 发布、最终发行包验收分别进行。

## 2026-10-24 源码业务域整理

- renderer 按 `app/` 与 `features/` 组织，跨 renderer、Electron 和测试共用的纯逻辑移至 `DesktopUI/shared/`。
- Electron 主进程业务按 worlds、profiles、game、reload、editor、automation、client、performance 归入 `electron/domains/`；装配、IPC、服务和隔离基础设施保持原边界。
- 构建、测试、WASM 路径和架构文档同步更新；新增结构边界回归测试，未改变 IPC、数据格式、运行时目录或业务实现。
- 当前设备验证：串行服务测试 301/301；常规 UI、调试 UI、多主机、房间、MCDK 运行链、发行包和发行房间 UI 均通过。常规服务测试并发模式曾受 Windows 进程枚举超时影响，串行复测通过。
